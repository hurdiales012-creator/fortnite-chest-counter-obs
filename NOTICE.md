# Créditos y recursos

El código y la documentación originales de este repositorio se distribuyen bajo MIT.

`assets/marco.png` es una ilustración generada con una herramienta de IA para representar un marco de contador: cofre de fantasía, borde dorado, gemas y medallón. No se extrajo de una grabación del juego. Las capturas del panel y del contador en `docs/images/` usan exclusivamente el modo de demostración. La guía de conexión es un esquema ilustrado.

Fortnite, sus marcas y elementos identificativos pertenecen a sus respectivos titulares. La licencia de este código no otorga derechos sobre marcas de terceros ni implica afiliación o respaldo. OBS Studio también es un proyecto independiente.

Dependencias principales: Python, NumPy, OpenCV, RapidOCR/ONNX Runtime y obsws-python. Se instalan desde sus distribuciones originales y conservan sus propias licencias. No se incluyen ejecutables de otros contadores, grabaciones ni repeticiones de Fortnite.
